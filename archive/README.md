# Archive

The v0 role skills: `audience-student`, `audience-collaborator`,
`audience-advisor`, `audience-prompter`, `team-norms`. Superseded as a product
by [`skills/know-your-audience/`](../skills/know-your-audience/SKILL.md),
which interviews you and generates a skill for your actual audience instead of
a fixed role.

Kept, not deleted, for two reasons: they are the priors `know-your-audience`
reads from and specializes when it generates a new skill, and they are the
history of the two-axes framing that the README still uses.

Do not install these directly or extend them. New work goes through
`know-your-audience`.
